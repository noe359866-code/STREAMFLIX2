# FlixLatam — Nuvio provider

Adaptación segura del scraper compartido. Busca por título, identifica película o episodio por temporada y número, y solo devuelve URLs HTTPS HLS directas encontradas en el HTML. No implementa el cálculo PoW, descifrado AES, extracción de enlaces cifrados ni resolución de reproductores externos. El plugin necesita título en mediaInfo o como primer argumento textual.
