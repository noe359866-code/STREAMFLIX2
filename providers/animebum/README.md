# AnimeBum — Nuvio provider

Adaptación JavaScript del scraper compartido. Busca por título, navega a la página de serie/episodio y solo devuelve URLs HTTPS HLS directas visibles en el HTML. Los iframes y servidores externos no se resuelven. La disponibilidad real depende de que la fuente publique HLS directo. El plugin necesita título en mediaInfo o como primer argumento textual.
